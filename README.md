# CodeAlpha Hangman Game

A beginner-friendly console Hangman game built in Python for the CodeAlpha internship.

## Features
- Five predefined fruit words, each with a helpful hint
- One randomly selected letter revealed at the start
- Six allowed incorrect guesses
- Displays the hidden word and reveals all occurrences of guessed letters
- Rejects invalid inputs and repeated guesses
- Win and loss messages

## Run

```bash
python hangman.py
```

## Concepts
Python dictionaries, lists, strings, loops, conditionals, `random.choice()`, and input validation.
